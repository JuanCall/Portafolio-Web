01 · Conóceme

Sobre Mí

Soy estudiante de Ingeniería de Sistemas (último ciclo, egreso 2026) y desarrollador de software enfocado en desarrollo web y móvil. Construyo soluciones completas: aplicaciones de escritorio con Electron, APIs REST con Node.js, aplicaciones móviles con React Native y sitios web desplegados en la nube con Firebase.

Desarrollé de forma integral un sistema de Punto de Venta (POS) para restaurantes con sincronización en tiempo real entre caja, meseros y web. Me destaco por transformar procesos manuales en sistemas eficientes: gestión de salón, cobros, inventario y reportes, combinando sólidas habilidades técnicas con liderazgo y comunicación efectiva con usuarios no técnicos.

03 · Trabajos

FLAGSHIP2026

Calletano POS

Sistema de Punto de Venta para Restaurantes con tres componentes sincronizados en tiempo real: caja de escritorio (Electron + React), app móvil POS-Mozo (React Native/Expo/TypeScript) y web. API REST y tiempo real con Socket.IO sobre SQLite, autenticación segura (bcrypt), validación (Zod) y logging (Winston). Gestión de salón, cobros mixtos, boletas con QR SUNAT, arqueo de caja, dashboard gerencial (Chart.js), inventario, delivery, club de clientes e instalador de Windows (NSIS).
